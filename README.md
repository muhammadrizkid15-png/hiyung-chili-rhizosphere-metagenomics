# Hiyung Chili Rhizosphere Metagenomics

## Overview
This repository contains scripts and analysis pipelines 
for taxonomic profiling and functional metagenomics of 
Hiyung chili (*Capsicum frutescens* L.) rhizosphere 
microbiome under bacterial wilt conditions.

## Papers
- **Paper 1:** Taxonomic profiling of Hiyung chili 
  rhizosphere microbiome (under review)
- **Paper 3:** Functional metagenomics of Hiyung chili 
  rhizosphere microbiome (in preparation)

## Methods
- Sequencing: Oxford Nanopore Technology (ONT)
- Assembly: metaFlye v2.9
- Binning: MetaBAT2
- MAG Quality: CheckM2
- Taxonomy: GTDB-Tk
- Functional annotation: eggNOG-mapper v2
- CAZyme: dbCAN3
- BGC: antiSMASH 7.0
- Visualization: R v4.6.0
